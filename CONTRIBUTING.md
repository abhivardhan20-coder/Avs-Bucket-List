# Contributing to AV's Bucket List

## Development Workflow
1. Fork the repo and create your branch from main.
2. Run pnpm install at the root.
3. Set up the required environment variables locally.
4. Verify tests pass with pnpm test.

## Pull Request Guidelines
- Ensure your code follows the existing style conventions.
- Write or update tests for any new functionality.
- Verify the bundle size is not bloated with unused dependencies using 
px depcheck.
- Run pnpm typecheck before pushing.

Thank you for your contributions!
